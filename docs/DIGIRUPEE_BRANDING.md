# digiRupee Android branding

The Android application is branded as **digiRupee**.

- Launcher/app name: digiRupee
- Launcher artwork: generated digiRupee rupee-D neon icon supplied in the project assets
- Android WebView user agent suffix: digiRupee/1.0
- Website remains branded LOKTRON; this branding change is Android-only.
- The Android app loads the live LOKTRON website at `https://tronpay-production.up.railway.app/`, so the APK uses the same UI, login, orders and admin-backed logic as production web.
- APK artifacts are published by GitHub Actions as `digiRupee-apks`.
